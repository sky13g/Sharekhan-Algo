📈 Sharekhan Automated F&O Paper Trading EngineAn enterprise-grade, asynchronous Python algorithm built with FastAPI, Asyncio, and Uvicorn to simulate automated Options trading on the National Stock Exchange (NSE). The strategy evaluates real-time market data to track moving average crossovers while offering complete structural management through Telegram Messenger.🛠️ System Architecture & Core LogicThis script acts as a headless, stateful trading terminal that operates continuously in a background thread. It is split into four distinct logic layers:1. The Strategy Signal EngineAsset Tracked: NIFTY 50 Index (^NSEI) via high-frequency market polling.Technical Indicator: Dual Exponential Moving Averages (EMA 5 and EMA 10) evaluated on a 1-minute close interval.Execution Trigger:🟢 Bullish Crossover (EMA 5 > EMA 10): Flattens any existing short positions and initiates a Buy Call Option (CE) entry signal.🔴 Bearish Crossover (EMA 5 < EMA 10): Flattens any existing long positions and initiates a Buy Put Option (PE) entry signal.2. Automated Contract Selection MatrixThe algorithm automatically tracks index spot values to map precise dynamic options derivative instruments.Strike Rounding: Rounds the NIFTY spot to the nearest 50-point strike cluster (e.g., if NIFTY is at 24,324, it targets the 24,300 strike).Dynamic Expiry Mapping: Programmatically extracts current calendar timestamps to build the exact Sharekhan contract trading symbol string matching current monthly options series (e.g., NIFTY26JUL24300CE).Scrip Master Synchronization: On boot, the engine downloads the official, active multi-gigabyte Sharekhan contract master file (ScripMaster.txt) directly from their database to extract the underlying database ScripCode for live tick tracking.3. Institutional Risk ManagementOnce a paper position is registered in the engine's ledger, a sub-second tracker evaluates the asset's Last Traded Price (LTP) against strict risk metrics:Hard Stop Loss (SL): Fixed at 10% below the initial entry price to protect capital.Take Profit Target (TP): Fixed at 20% above the entry price to lock in automated gains.Trailing Stop Loss Tracker: Features a 5% trailing ratchet. As the option premium moves in your trade's favor, the stop-loss level climbs continuously, lock-stepping behind peak profitability and mitigating reversal risks.4. Intra-Day Clearing WindowActive Hours: The loop monitors data between 9:15 AM and 3:30 PM IST.Weekend Protection: The background manager checks the active day. If the day matches Saturday or Sunday, it places the engine into a low-resource hibernation state for 1 hour before checking again.EOD Auto-Squareoff: At precisely 3:30 PM IST, the loop executes an emergency override that flattens any open exposure at market price, tallies daily performance metrics, and broadcasts a session breakdown summary report to Telegram.🔐 Interactive Authentication & Login FlowBecause Sharekhan requires daily interactive multi-factor authentication (MFA), the engine utilizes an event-driven webhook handshake to log in without storing passwords or 2FA secrets on the server.
