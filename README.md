Sharekhan High-Frequency Tick Options Trading EngineAn enterprise-grade, asynchronous Python algorithmic engine built using FastAPI, Asyncio, and native WebSockets. The system establishes a direct, persistent network stream with the exchange to process market changes tick-by-tick, executing mathematical strategy evaluations purely in memory.
🛠️ System Architecture & Core LogicThis script runs as a headless, stateful trading terminal operating continuously inside a background thread worker execution structure. It is split into four distinct logic layers:1. The Strategy Signal EngineAsset Tracked: NIFTY 50 Index (^NSEI) via low-latency streaming tickers.Technical Indicator: Dual Exponential Moving Averages (EMA 5 and EMA 10) evaluated on a 1-minute close interval.Execution Trigger:🟢 Bullish Crossover (EMA 5 > EMA 10): Flattens open short positions and triggers a Buy Call Option (CE) entry signal.🔴 Bearish Crossover (EMA 5 < EMA 10): Flattens open long positions and triggers a Buy Put Option (PE) entry signal.2. Low-Latency TBT Stream WorkerWebSocket Tunneling: Replaced standard REST API polling with an open binary WebSocket connection directly to the exchange network stream.Memory Candle Compilation: Collects high-frequency tick payloads inside an array, compresses the data stream at the end of every 60-second window into an exact 1-minute close price, and updates a rolling memory buffer.3. Institutional Risk ManagementOnce a position is entered, a sub-second tracker evaluates the asset's Last Traded Price (LTP) against structural safety flags:Hard Stop Loss (SL): Fixed at 10% below the initial entry price to protect capital.Take Profit Target (TP): Fixed at 20% above the entry price to lock in automated gains.Trailing Stop Loss Tracker: Features a 5% trailing ratchet that climbs continuously behind peak profitability to lock in gains and protect against sharp market reversals.4. Intra-Day Clearing WindowActive Hours: The loop monitors data between 9:15 AM and 3:30 PM IST.EOD Auto-Squareoff: At precisely 3:30 PM IST, the loop flattens any open exposure at market price, tallies daily performance metrics, resets historical buffers, and broadcasts a session breakdown summary report to Telegram.🔐 Interactive Authentication & Login FlowBecause Sharekhan requires daily interactive multi-factor authentication (MFA), the engine utilizes an event-driven webhook handshake to log in without storing passwords or 2FA secrets on the server.System Boot: The server initializes an asynchronous startup routine, connects to Sharekhan's authentication endpoint using your API credentials, and generates a short-lived request token.2FA Trigger: The engine pushes an encrypted notification to your private Telegram chat, prompting you for your 2FA passcode.MFA Interception: The trading engine pauses all tracking loops and enters an active waiting state.OTP Handshake Completion: You text the 4-to-6-digit broker OTP straight into your Telegram bot chat window. The API endpoint captures this input, passes it to the validation endpoint, saves the finalized token inside a secure temporary directory, and activates the live streaming loops.📱 Telegram Interactive Chat CommandsYou can monitor and manage your trading bot from anywhere using three secure chat commands:📌 /status: Compiles current tracking statistics. Returns the open position type, entry premium, real-time token value, realized session P&L, and draws a clean text-based technical visualizer chart showing current EMA crossover spreads.⚙️ /lot <count>: Changes trading lot parameters instantly mid-session (e.g., /lot 5). Updates underlying calculation matrices safely between an allowed range of 1 and 20 lots.🚨 /squareoff: Instantly triggers a manual market exit.
